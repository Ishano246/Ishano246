## Selected projects

### [TrustGate Credit](https://github.com/Indrajeet-Badhel/trustgate-credit)
Designed an explainable credit-risk framework that weighs repayment history according to its reliability. Compared four model variants to study how repayment data affects predictive performance and score stability for applicants with limited credit history.

### [Contact Builder](https://github.com/Indrajeet-Badhel/Contact-Builder)
Built a pipeline that extracts and validates contact data from PDFs, slides, images, URLs, and CSVs. The application adds semantic search, confidence scores, graph visualization, and CRM-ready exports.

### [Multi-Agent AI Interview Simulator](https://github.com/Indrajeet-Badhel/MULTI_AGENTIC_INTERVIEW_COMPANION)
Built agents for question generation, answer evaluation, scoring, feedback, and reporting. Integrated Ollama, Hugging Face, and DeepFace.

### Multimodal Knowledge Graph
Built a pipeline that uses language models and embeddings to extract entities and relationships, resolve duplicates, and visualize connections weighted by confidence.
